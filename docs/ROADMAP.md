# PlayzAI Roadmap

## Phase 1
- Secure device registration
- Authentication
- Audit log
- Allowlisted PC actions
- Panic mode
- Android client scaffold

## Phase 2
- WebSocket signed task channel
- STT/TTS provider abstraction
- Hindi/English/Hinglish routing
- Voice selection
- Android voice UI
- WhatsApp Business Cloud API adapter

## Phase 3
- OBS integration
- Browser automation through allowlisted actions
- Wake-on-LAN gateway
- Scheduling
- Device approval UI
- Security alert delivery to WhatsApp

## Phase 4
- Production deployment: TLS, reverse proxy, secrets manager, PostgreSQL, Redis, backups, monitoring, code signing, Android app signing, penetration testing.
